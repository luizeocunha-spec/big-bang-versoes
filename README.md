# Big Bang - versoes

Este repositorio guarda so as versoes publicadas do Big Bang (instalador e
pacotes de atualizacao). O codigo-fonte nao fica aqui.

## Instalar

1. Abra a [ultima versao](../../releases/latest) e baixe **BigBang_Setup.exe**.
2. Execute. Nao precisa de Python nem de administrador.
   Se o Windows avisar que o programa nao e reconhecido, clique em
   **Mais informacoes** e depois em **Executar assim mesmo**.
3. Abra pelo atalho **Big Bang** (menu Iniciar ou Area de Trabalho).

## Atualizacoes

Sao automaticas e obrigatorias: ao abrir, o Big Bang baixa a versao mais nova
(e confere cada arquivo pelo SHA-256 publicado em `versoes.json`).

Se uma versao der problema, clique em **versao ... (trocar)** no alto da
janela, ou use o atalho **Big Bang - escolher versao**, e escolha uma
anterior. Ela fica em uso ate sair uma versao nova.
